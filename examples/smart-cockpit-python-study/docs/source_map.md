## 教学实现的边界

`framework_reference` 展开原框架职责，用本地订阅和 `asyncio` 实现会话、任务及通知。
离线模型、终端客户端和演示数据属于学习设计，不是原模型供应商、浏览器 UI 或生产协议实现。
当前 `BackendPort`、Provider、状态存储及调度是演示所需的子集；完整契约请读对应原源码。
